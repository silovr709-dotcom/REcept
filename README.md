# РЕцепт — сайт семейного мебельного ателье (Тверь)

Конверсионный сайт мебельного ателье «РЕцепт». Главная задача сайта — не
«показать красивые кухни», а довести посетителя до обращения к Роберту и Кате.

**Стек:** Next.js 15 (App Router) · React 19 · TypeScript · Tailwind CSS v4 ·
self-hosted шрифты · без анимационных библиотек.

---

## 🚀 Быстрый старт

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # production-сборка
npm start       # запуск production-сборки
npm run typecheck
```

## ⚠️ Что нужно заполнить перед публикацией

Сайт сознательно построен так, чтобы **нигде не было выдуманных данных**.
Всё, чего мы пока не знаем, отсутствует, а не заменено «рыбой». Ниже — список
того, что нужно вписать. Все правки делаются в 2–3 файлах.

### 1. Контакты — `src/data/site.ts`

Самое важное. Сейчас все каналы связи стоят как `null`, поэтому на сайте
**не показывается ни один телефон и мессенджер** — работает только форма.

```ts
const PHONE_DISPLAY = '+7 900 000-00-00';   // как видит человек
const PHONE_RAW     = '+79000000000';       // для tel:
const TELEGRAM_USERNAME = 'recept_tver';    // без @
const WHATSAPP_RAW  = '79000000000';
const VK_ID         = 'recept_tver';
const EMAIL         = 'hello@recept-tver.ru';
const ADDRESS       = 'Тверь, ул. Примерная, 1';
const ADDRESS_MAP_URL = 'https://yandex.ru/maps/-/...';
export const WORKING_HOURS = 'Пн–Сб, 10:00–19:00';
```

Логика рендеринга: **заполнено — появилось на сайте, `null` — канала просто
нет**. Ничего доделывать в компонентах не нужно. Заполненные контакты
автоматически появятся в шапке, подвале, мобильной панели, модальной форме,
на странице «Контакты» и в микроразметке для поисковиков.

Там же задаётся домен:

```ts
url: process.env.NEXT_PUBLIC_SITE_URL ?? 'https://recept-tver.ru',
```

### 2. Куда приходят заявки — `.env.local`

Скопируйте `.env.example` в `.env.local` и заполните доступы к почте:

```
SMTP_HOST=smtp.yandex.ru
SMTP_PORT=465
SMTP_USER=hello@recept-tver.ru
SMTP_PASSWORD=пароль_приложения
LEAD_EMAIL_TO=hello@recept-tver.ru
LEAD_EMAIL_FROM="Сайт РЕцепт" <hello@recept-tver.ru>
NEXT_PUBLIC_SITE_URL=https://recept-tver.ru
```

Пока почта не настроена, заявки **не теряются**: они пишутся в
`.leads/leads.jsonl` и в логи сервера, а человек всё равно видит нормальное
подтверждение. После настройки SMTP письма пойдут на почту, вместе с
прикреплёнными фотографиями помещения.

### 3. Фотографии Роберта и Кати — `public/images/team/`

Положите файлы и укажите их в `src/data/content.ts`:

```ts
export const team = [
  { name: 'Роберт', role: 'Производство и монтаж', bio: '…', photo: '/images/team/robert.jpg' },
  { name: 'Катя',   role: 'Проектирование',        bio: '…', photo: '/images/team/katya.jpg' },
];
```

`role` и `bio` заполняйте **только реальной информацией** — сейчас они `null`,
и блок корректно работает без них.

### 4. Отзывы — `src/data/content.ts`

Массив `testimonials` пуст намеренно: выдуманные отзывы мы не публикуем.
Секция отзывов уже написана и **появится на сайте автоматически**, как только
в массиве окажется хотя бы один реальный отзыв:

```ts
export const testimonials: Testimonial[] = [
  { author: 'Анна', text: 'Реальный текст отзыва', source: 'Авито', url: 'https://…' },
];
```

### 5. Детали и фактуры — `src/data/details.ts`

Чтобы сайт выглядел как сайт **индивидуальной** мебели, а не каталог, по всем
страницам разложены макро-кадры: профиль-ручка, кромка камня, рифлёное стекло,
подсветка под корпусом, стыки фактур. Это не сток и не отдельная съёмка —
каждый кадр вырезан из ваших же фотографий в исходном разрешении.

Чтобы добавить новый фрагмент: положите файл в `public/images/details/`,
импортируйте его в `details.ts`, опишите, что на кадре, и укажите
слаг проекта-источника. Кадр сам появится в галереях и на странице проекта
(через поле `detailIds` в `projects.ts`).

Когда появятся настоящие макро-снимки фурнитуры — просто замените файлы.

### 6. Новые проекты в портфолио — `src/data/projects.ts`

1. Положите фотографию в `public/images/kitchens/` (или в отдельную папку).
2. Импортируйте её и добавьте объект в массив `projects`.

Поля `area`, `term`, `budget`, `clientStory` сейчас `null` у всех проектов —
мы не придумывали метражи, сроки и истории заказчиков. Если реальные данные
появятся, впишите их: они автоматически отрисуются на странице проекта.

## 🎯 Конверсионная логика

Путь посетителя: **внимание → интерес → понимание → доверие → снятие страха →
желание обсудить → контакт.**

| Блок | Какую задачу решает |
|---|---|
| Hero | За 5 секунд: что, где, кто, чем отличается, что нажать |
| «Мы забираем головную боль» | Главная боль клиента: он один между мебельщиком и прорабом |
| Что мы делаем | Расширяет запрос: не только кухни |
| Портфолио | Визуальное доказательство → сразу возврат к действию |
| Процесс из 10 шагов | Снимает страх неизвестности + показывает, как мало нужно от клиента |
| Когда приходить | Честная причина не откладывать (вместо фейковой срочности) |
| Преимущества | Каждое условие связано с выгодой, а не с иконкой |
| Цена | Объясняет, почему нет прайса, и предлагает бесплатный расчёт |
| Роберт и Катя | Персональная ответственность вместо «нашей команды» |
| Возражения | Отвечает на «а если…» до того, как человек уйдёт |
| FAQ | Добивает остаточные вопросы |
| Финальный CTA | Не «спасибо за внимание», а приглашение к разговору |

**Единая механика CTA.** Все кнопки — компонент `CtaButton`. Он открывает
короткую форму поверх страницы, поэтому человек не теряет контекст и не
скроллит в конец. Заголовок формы меняется под контекст кнопки. Если JS не
загрузился, кнопка ведёт к форме `#zayavka` внизу страницы.

**Форма.** Три поля (имя, контакт, комментарий) + необязательные вложения.
Рядом всегда объяснено, что будет дальше, и что это ни к чему не обязывает.
После отправки человек видит не «Спасибо!», а описание следующего шага.

**Чего на сайте нет и не будет:** выдуманных отзывов и цифр, зачёркнутых цен,
таймеров, «только сегодня», «№1 в Твери», стоковых фотографий.

## ⚡️ Производительность и доступность

- Все изображения — через `next/image`: AVIF/WebP, responsive `srcset`,
  lazy-loading, blur-placeholder, `priority` только для LCP-кадра.
- Шрифты self-hosted (`woff2`, кириллица отдельным subset), `preload`
  + `font-display: swap`. Внешних CDN нет.
- Анимации — только CSS + `IntersectionObserver`, без анимационных библиотек.
  First Load JS ≈ 119 кБ.
- `prefers-reduced-motion` отключает всю анимацию, включая заставку.
- Семантическая разметка, один `h1` на страницу, `alt` у всех изображений,
  видимый фокус, ловушка фокуса в модальном окне, skip-link, контраст текста
  проверен по WCAG AA.
- Заставка загрузки не задерживает: уходит сразу после `load`, при повторном
  визите — ускоренная версия, при отключённом JS не показывается вовсе,
  плюс два независимых страховочных таймера.
  Длительность меняется одной строкой в `src/components/LoaderController.tsx`
  (`minDuration`: 1700 мс на первый визит, 500 мс на повторный).

## 📦 Деплой

Подойдёт любая площадка с поддержкой Node.js (Vercel, Timeweb Cloud, Selectel,
свой VPS):

```bash
npm ci
npm run build
npm start          # или pm2 / systemd
```

Не забудьте переменные окружения из `.env.example` и реальный
`NEXT_PUBLIC_SITE_URL` — от него зависят canonical-ссылки, sitemap и OG.

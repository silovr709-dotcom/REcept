# РЕцепт — сайт семейного мебельного ателье (Тверь)

Конверсионный сайт мебельного ателье «РЕцепт». Главная задача сайта — не
«показать красивые кухни», а довести посетителя до обращения к Роберту и Кате.

**Стек:** Next.js 15 (App Router) · React 19 · TypeScript · Tailwind CSS v4 ·
self-hosted шрифты · без анимационных библиотек.

---

## 🚀 Быстрый старт

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # production-сборка
npm start       # запуск production-сборки
npm run typecheck
```

## ⚠️ Что ещё нужно проверить и дополнить

### 1. Собственное производство — сверьте формулировку

Во ВКонтакте вы сами разбираете вопрос «почему у нас нет собственного
производства». Поэтому я убрал с сайта все утверждения вида «мы производим» и
переформулировал честно: заказ размещается на производстве, а проектирование,
контроль, доставка и сборка — на вас. Текст в `src/data/content.ts`
(шаг 07 процесса и вопрос «У вас есть собственное производство?») —
**перечитайте и поправьте под свою формулировку.**

### 2. Роли Роберта и Кати

Сейчас у обоих стоит «Руководитель» — так указано в карточках во ВКонтакте.
Если хотите разделить зоны ответственности (например, проектирование и
монтаж), впишите в `src/data/content.ts` → `team`.

### 3. Фотографии Роберта и Кати — `public/images/team/`

Положите файлы и укажите путь в поле `photo`. Блок корректно работает и без
них, но живые лица усиливают весь раздел «О нас».

### 4. Куда приходят заявки — `.env.local`

Скопируйте `.env.example` в `.env.local`:

```
SMTP_HOST=smtp.yandex.ru
SMTP_PORT=465
SMTP_USER=tver-kuhni11@yandex.ru
SMTP_PASSWORD=пароль_приложения_Яндекс_Почты
LEAD_EMAIL_TO=tver-kuhni11@yandex.ru
LEAD_EMAIL_FROM="Сайт РЕцепт" <tver-kuhni11@yandex.ru>
NEXT_PUBLIC_SITE_URL=https://tver-kuhni.ru
```

Для Яндекс Почты нужен **пароль приложения**, а не обычный пароль от аккаунта.

Пока почта не настроена, заявки **не теряются**: они пишутся в
`.leads/leads.jsonl` и в логи сервера, а человек видит нормальное
подтверждение.

### 5. Часы работы

Полного расписания мы не знаем (на Яндекс Картах видно только открытие в
10:00), поэтому текстом его не пишем — актуальное показывает виджет карты.
Если хотите зафиксировать, впишите `WORKING_HOURS` в `src/data/site.ts`.

### 6. Telegram и WhatsApp

Если заведёте — раскомментируйте `TELEGRAM_USERNAME` / `WHATSAPP_RAW`
в `src/data/site.ts`, кнопки появятся сами.

## 🧩 Как добавлять контент

### Новые проекты — `src/data/projects.ts`

Положите фотографию в `public/images/kitchens/`, импортируйте её и добавьте
объект в массив `projects`. Поля `area`, `term`, `budget`, `clientStory`
сейчас `null` у всех проектов — мы не придумывали метражи, сроки и истории
заказчиков. Появятся реальные данные — впишите, они отрисуются сами.

### Свежие отзывы — `src/data/reviews.ts`

Скопируйте текст с Яндекс Карт дословно, укажите автора и дату, поправьте
цифры в `rating`. Виджет на `/otzyvy` обновляется сам.

### Детали и фактуры — `src/data/details.ts`

18 макро-кадров (профиль-ручка, кромка камня, рифлёное стекло, подсветка)
вырезаны из ваших же фотографий в исходном разрешении. Чтобы добавить новый:
файл в `public/images/details/`, импорт в `details.ts`, слаг проекта-источника.

## 🎯 Конверсионная логика

Путь посетителя: **внимание → интерес → понимание → доверие → снятие страха →
желание обсудить → контакт.**

| Блок | Какую задачу решает |
|---|---|
| Hero | За 5 секунд: что, где, кто, чем отличается, что нажать |
| «Мы забираем головную боль» | Главная боль клиента: он один между мебельщиком и прорабом |
| Что мы делаем | Расширяет запрос: не только кухни |
| Портфолио | Визуальное доказательство → сразу возврат к действию |
| Процесс из 10 шагов | Снимает страх неизвестности + показывает, как мало нужно от клиента |
| Когда приходить | Честная причина не откладывать (вместо фейковой срочности) |
| Преимущества | Каждое условие связано с выгодой, а не с иконкой |
| Цена | Объясняет, почему нет прайса, и предлагает бесплатный расчёт |
| Роберт и Катя | Персональная ответственность вместо «нашей команды» |
| Возражения | Отвечает на «а если…» до того, как человек уйдёт |
| FAQ | Добивает остаточные вопросы |
| Финальный CTA | Не «спасибо за внимание», а приглашение к разговору |

**Единая механика CTA.** Все кнопки — компонент `CtaButton`. Он открывает
короткую форму поверх страницы, поэтому человек не теряет контекст и не
скроллит в конец. Заголовок формы меняется под контекст кнопки. Если JS не
загрузился, кнопка ведёт к форме `#zayavka` внизу страницы.

**Форма.** Три поля (имя, контакт, комментарий) + необязательные вложения.
Рядом всегда объяснено, что будет дальше, и что это ни к чему не обязывает.
После отправки человек видит не «Спасибо!», а описание следующего шага.

**Чего на сайте нет и не будет:** выдуманных отзывов и цифр, зачёркнутых цен,
таймеров, «только сегодня», «№1 в Твери», стоковых фотографий.

## ⚡️ Производительность и доступность

- Все изображения — через `next/image`: AVIF/WebP, responsive `srcset`,
  lazy-loading, blur-placeholder, `priority` только для LCP-кадра.
- Шрифты self-hosted (`woff2`, кириллица отдельным subset), `preload`
  + `font-display: swap`. Внешних CDN нет.
- Анимации — только CSS + `IntersectionObserver`, без анимационных библиотек.
  First Load JS ≈ 119 кБ.
- `prefers-reduced-motion` отключает всю анимацию, включая заставку.
- Семантическая разметка, один `h1` на страницу, `alt` у всех изображений,
  видимый фокус, ловушка фокуса в модальном окне, skip-link, контраст текста
  проверен по WCAG AA.
- Заставка загрузки не задерживает: уходит сразу после `load`, при повторном
  визите — ускоренная версия, при отключённом JS не показывается вовсе,
  плюс два независимых страховочных таймера.
  Длительность меняется одной строкой в `src/components/LoaderController.tsx`
  (`minDuration`: 1700 мс на первый визит, 500 мс на повторный).

## 📦 Деплой

Подойдёт любая площадка с поддержкой Node.js (Vercel, Timeweb Cloud, Selectel,
свой VPS):

```bash
npm ci
npm run build
npm start          # или pm2 / systemd
```

Не забудьте переменные окружения из `.env.example` и реальный
`NEXT_PUBLIC_SITE_URL` — от него зависят canonical-ссылки, sitemap и OG.
